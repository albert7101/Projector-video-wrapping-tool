# Projector Media Canvas (Lite)

An offline projector video and image mapping canvas. The Lite app is a standalone page and does not use Gemini or any online API.

## Run locally

**Prerequisite:** Node.js

No package installation or API key is required. From this folder, run:

`node server.mjs`

Then open http://localhost:3000/.

You can also use `npm run dev`, which starts the same lightweight, dependency-free server.
